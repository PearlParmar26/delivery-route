Learn the algorithms

Greedy

Always drive to the closest stop you haven't visited yet. Super fast, but can miss the best route.

O(n²)

Dynamic Programming

Held-Karp remembers the best path for every set of visited stops, so no sub-route is solved twice.

O(n²·2ⁿ)

Branch & Bound

Explores partial routes but cuts off any branch whose lower bound can't beat the best route found so far.

O(n²·n!) worst

Brute Force

Tries every possible order. Always right, but 10 stops already means 362,880 routes.

O(n·n!)
